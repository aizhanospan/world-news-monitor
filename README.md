# Монитор мировых новостей

Реализация PRD.md: единая хронологическая лента новостей с сайтов и Telegram-каналов, перевод на русский, краткое изложение (2–3 предложения), категории, флаг «Срочно», темы, ссылки «Статья» и «Источник».

## Запуск

```
copy .env.example .env      # вписать ANTHROPIC_API_KEY
npm start
```
Открыть http://localhost:3000. Нужен Node.js 20+, зависимостей нет.

## Как устроено
- `server.js` — опрос RSS и публичных Telegram-каналов (`t.me/s/<канал>`) каждые 60 с, определение новых по времени публикации, обработка через Claude (перевод, сжатие, категория, срочность), теги по ключевым словам, отдача ленты (SSE, обновление в реальном времени), необязательные уведомления в Telegram-бот.
- `public/index.html` — лента, фильтры (категории, «Срочно», темы — комбинируются).
- `sources.json` — источники. **Проверьте адреса RSS и названия Telegram-каналов** — часть указана по догадке; для Reuters, AP, IDF, КСИР официального RSS нет (используется Google News).
- `topics.json` — пользовательские темы (добавляйте свои: id, название, ключевые слова).

## Без ключа Claude
Работает упрощённый режим: без перевода, категория и срочность определяются по ключевым словам.

## Не реализовано (открытые вопросы PRD)
Поиск/архив, интерфейс управления темами, Telegram-каналы без публичного веб-просмотра (нужен Telethon/MTProto).
